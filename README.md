# OptimizationProject
This repository is for the project named " Optimizing Skill Allocation to Reduce Unemployment Using PLFS 2023–24 Data". Saving all the necessary codes and datasets that we used for this project.
## Specifications:
The ".csv" files are datasets that has been used in the project , some datasets are in ".pdf" format as well.
Codes to regenerate the results are indicated for specific aspects of the total project.(Extra datasets and secondary aspects of the project is covered in the physical documentation of the project).
